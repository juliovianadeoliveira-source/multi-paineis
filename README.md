# Multi Painéis

Painel web desenvolvido para o gerenciamento de rotas, ativos e configurações de revenda.

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estrutura das páginas.
* **CSS3**: Estilização e layout responsivo.
* **JavaScript**: Lógica e interatividade dinâmicas.

## 📂 Estrutura do Projeto

* `index.html`: Página principal e layout base.
* `style.css`: Folha de estilos do painel.
* `script.js`: Arquivo de funções e comportamento.
* `img/`: Pasta com logotipos e imagens de fundo.
* `icons/`: Ícones utilizados na interface.
* `fonts/`: Fontes personalizadas do sistema.

## ⚙️ Como Executar

1. Baixe ou clone este repositório em sua máquina.
2. Abra a pasta do projeto no **VS Code**.
3. Utilize uma extensão como o **Live Server** para abrir o arquivo `index.html` diretamente no navegador.
